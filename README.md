# Adriano Ramos — Portfólio

Portfólio pessoal estático, desenvolvido com HTML, CSS e JavaScript. Apresenta projetos acadêmicos e pessoais, conhecimentos, formação, experiência e contatos.

## Abrir

Abra `index.html` no navegador. Para usar um servidor local, na pasta do projeto:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Acesse `http://127.0.0.1:8765`. Não há dependências para instalar nem etapa de build.

## Recursos

- Layout responsivo e navegação móvel.
- Temas claro e escuro, com preferência salva quando o navegador permite.
- Filtros por categoria e detalhes dos sete projetos.
- Links diretos para os repositórios, LinkedIn e e-mail.
- Cópia de e-mail em contextos seguros compatíveis com Clipboard API.
- Animações leves, respeitando a preferência por movimento reduzido.
- Navegação por teclado, link para pular conteúdo e modais nativos.
- Conteúdo principal e links disponíveis mesmo sem JavaScript.

## Editar

- `index.html`: apresentação, projetos, competências, trajetória e contatos.
- `styles.css`: cores, tipografia, espaçamento e responsividade.
- `app.js`: filtros, detalhes, menu, tema, cópia do e-mail e animação.
- `assets/`: imagens reais dos projetos e favicon.

Os detalhes dos projetos estão no objeto `details` de `app.js`; mantenha-os alinhados às descrições de `index.html`. Imagens foram copiadas dos respectivos projetos e seus dados são demonstrativos. O ParceiroAuto está identificado como projeto em desenvolvimento.

## Antes de publicar

Confira os nomes e o status dos cursos, as datas profissionais e as descrições dos projetos. Caso queira, acrescente responsabilidades concretas de suas experiências e uma foto pessoal. O contato usa LinkedIn, GitHub e `adriannoordsj@gmail.com`, sem formulário ou serviço de envio.

O site pode ser hospedado como conteúdo estático. Nenhuma publicação, commit ou push é necessária para executá-lo localmente.
